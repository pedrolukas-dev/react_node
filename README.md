# react_node
# Nome do Projeto  Aplicação full-stack construída com React no frontend e Node.js no backend.  ### Tecnologias - React - Node.js - Express  ### Como rodar o projeto 1. Clone o repositório. 2. Rode `npm install` nas pastas do frontend e do backend. 3. Rode `npm start` (ou `npm run dev`) em ambas as pastas para iniciar a aplicação.
